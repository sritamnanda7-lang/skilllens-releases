# SkillLens releases

Downloads for [SkillLens](https://getskilllens.vercel.app), which shows which Claude skills and MCP tools were used per prompt, chat and project. This repo holds release files only.

## Install on a Mac

1. Download `SkillLens-0.3.0-universal.dmg` from [the latest release](https://github.com/sritamnanda7-lang/skilllens-releases/releases/latest).
2. Open it and drag SkillLens to Applications.
3. This build isn't signed or notarized yet. The first time, right-click SkillLens and choose **Open**, then **Open** again. On macOS 15 or later, if that's blocked, go to System Settings → Privacy & Security and click **Open Anyway**.

The Mac app reads Claude Code logs in `~/.claude/projects`. Apple silicon and Intel.
